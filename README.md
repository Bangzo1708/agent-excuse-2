A deterministic program that picks the funniest one-line excuse an AI agent gives its human after shipping a bug, scoring three hand-written candidates against the judge's five criteria and writing the winner to `/output/entry.txt`. Fully deterministic: no randomness, no clock, no network, no file reads.

## Run it

```sh
python3 main.py
```
